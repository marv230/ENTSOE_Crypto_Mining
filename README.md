# ENTSOE_Crypto_Mining
My small API project aimed at controlling Crypto miners based on the ENTSOE energy prices in Germany

This project is still in very early developement and there is currently no promise that this project will have a useable version.
Though it can provide code snippets for other projects that also utilise this API, which is why I want to try to focus on reuseability, but afterall it's just a personal project.
