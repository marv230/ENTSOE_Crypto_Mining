# ENTSOE_Crypto_Mining
## My small API project aimed at controlling crypto miners based on the ENTSOE day-ahead energy prices in European country price zones

This project is still in very early developement and there is currently no promise that this project will have a full version.
Other than that it can provide code snippets for other projects that also want to utilise this API, which is why I want to try to focus on reuseability, but afterall it's just a personal project.

Visit https://transparency.entsoe.eu/ for information on how about to get an API key or your price zone.
